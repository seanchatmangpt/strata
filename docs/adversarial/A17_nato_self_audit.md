# A17 NATO Self-Audit — Who Audits the Courts?

Adversarial lane A17. Subject: `strata_protocol/tests/nato/n01..n18` (6,811 lines,
read in full this session). Question: for each landed N-court, what would make it
PASS while the property it claims is actually violated? Four weakness classes:
vacuity paths (V), oracle weakness (O), calibrated-N under-coverage (N), scoping
substitution (S). No fixes applied. Read-only audit.

Verdict vocabulary: each weakness is a hypothesis about how the court fails to
constrain; none was executed as a mutation (that would be a fix-lane task).

## Head findings (evaluator-first ranking)

1. **N02 `pack_census` is tautological.** `before` and `after` are both
   `Dims::read(base.write())` — the same pure call on the same input
   (n02:96-98). The comparison can never fail; only the sentinel-diff test
   (n02:205) and `advance_census` carry real weight. The census *prints*
   exhaustiveness while proving nothing.
2. **N13's static table is self-graded.** The op-count rows are constants
   asserted equal to themselves (n13:374-379); nothing ties PNABI_COMMIT=28 to
   the actual source or disassembly of `pnabi.rs`. With TIMER_MARGIN=64x the
   measured leg tolerates a kernel 50x slower than claimed.
3. **N17 is a self-oracle (disclosed, but the disclosure is the finding).**
   PIPELINE-KAT vectors were generated by the signer under test; a fully
   wrong-but-deterministic signer passes every court. Only wire sizes (3309 /
   1952) anchor to FIPS 204 externally.
4. **N01/N08 share an oracle scoping hole.** `state_a` / `observe_clean`
   project to marking bits [15:0] only. A kernel that leaks B payload (or
   OCEL payload) into the committed word's non-marking fields passes both
   non-interference and power-analysis courts.
5. **N04's audit surface is a hardcoded module list.** Any new
   `src/consensus/*.rs` or kernel module not appended to `PROTOCOL_MODULES`
   carries ambient authority with zero findings.
6. **N03 defines the lattice it grades against.** No-write-down is checked
   against a demo classification chosen inside the test file; reclassifying
   the offending place to top_secret makes any declassification vanish.
7. **N11 hammer tier has no `aborts > 0` assertion.** `do_abort` is
   Bernoulli(0.1) per chunk; P(zero aborts across 40 chunks) ~ 1.5% — the
   torn-write court occasionally passes with the fault class never injected.

## Weakness-class totals

- Vacuity (V): N02 (tautology), N11 (abort-free pass) — 2 hard, plus latent
  V in every court whose anti-vacuity control exercises one mutation shape
  (N01, N05, N08 single-shape controls).
- Oracle weakness (O): N01, N03, N05, N08, N09, N10, N13, N17, N18 — the
  dominant class. Recurring pattern: the court re-derives the law from the
  same source it grades (N09/N10 `lawful_image`), grades against a lattice
  it defined (N03), or grades reproducibility instead of correctness (N17).
- Calibrated-N under-coverage (N): N05 (NaN pass), N07 (no ratio bound),
  N11 (abort floor), N14 (1 s ceiling), N15 (1/8-share floor), N13 (64x
  margin) — five courts convert a spec figure into a reported number plus a
  bound loose enough to be uninformative. Each is individually disclosed;
  collectively the pattern is "spec figure dropped, honest number printed,
  no falsifiable bound remains."
- Scoping substitution (S): N01 (projection), N04 (module list), N06 (single
  symbol), N12 (raw-boundary residual), N16 (token list), N18 (keyword
  filter) — each substitutes a nameable subset for the mandate; all are
  documented in-file, none is machine-checked as a coverage receipt.

## Ranking: what an evaluator finds first

1. N02 tautological census (code reads as self-contradicting in 3 lines).
2. N13 self-asserted table + 64x margin (the "deliverable" grades itself).
3. N17 self-oracle KAT cited as FIPS conformance risk (disclosure makes it
   findable; the risk is downstream overclaiming, not the test).
4. N03 self-owned lattice (BLP claim rests on the grader's own assignment).
5. N04 hardcoded module list (one `ls src/consensus` vs the list shows drift).
6. N11 missing abort-count floor (one-line absence, probabilistic pass).
7. N01/N08 marking-only projection (requires reading the oracle shape).
8. N15 1/8-share floor (requires noticing FLOOR derivation).
9. N05 NaN-passes (requires statistics reading).
10. N06/N12/N16/N18 scoping residuals (all disclosed; evaluator finds them
    only when tracing mandate -> delivered coverage).

## Cross-cutting meta-courts (the six that would catch the most)

1. **Mandate-coverage court**: for each N-lane, diff the spec-mandate figure
   in `docs/nato/NATO_N01_N20.md` against the delivered court's typed
   coverage; any substitution must be a machine-checked `SUBSTITUTED(domain)`
   marker, not prose (kills N01/N07/N12/N13/N14 disclosure-as-pass).
2. **Independent-oracle court**: any court whose oracle re-derives the law
   must derive it from a different artifact (doc table, ontology, second
   implementation) than the code under test (kills N09/N10 shared-spec, N07
   self-reference, N11 model-code drift).
3. **Mutation battery per court**: each court must fail on >= 1 injected
   defect of its own claimed class, beyond the single hand-written control
   (kills N02's tautology immediately; hardens N01/N03/N05/N08).
4. **Census-completeness court**: N04/N16/N18 enumerate their subject
   surfaces from the filesystem/AST, never from hand lists (kills list-drift
   scoping in three courts at once).
5. **Bound-informativeness court**: every "reported, not asserted" latency /
   scale figure must carry a falsifiable secondary bound at a stated
   fraction of the spec figure, or be typed UNSUPPORTED (kills the
   50x / 1 s / 1/8-share / 64x-margin looseness class).
6. **Receipt-integrity court**: N04/N06 courts write and then grade their
   own receipt JSON by string surgery; receipts must be schema-validated
   (`scripts/receipt_validate.py` exists) and written by the producer, not
   the grader.
